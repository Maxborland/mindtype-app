# Библиотека расшифровок MindType

> Статус: спецификация второго вертикального среза.
> Дата: 2026-07-30.

## Цель

Сделать сохраняемые расшифровки главным входом desktop-приложения: пользователь
видит документы после перезапуска, читает реплики с таймкодами, исправляет имена
собеседников и переключается между сохранёнными вариантами саммари.

Визуальная модель — картотека и два вложенных окна Mac OS System 7, а не
современный SaaS dashboard.

## Не входит в этот срез

- Редактирование текста и переназначение отдельных реплик.
- Запуск нового LLM-саммари и списание кредитов из библиотеки.
- Удаление документов и исходных файлов.
- Облачная синхронизация и совместный доступ.
- Полнотекстовый поиск.

## Acceptance criteria

- **UI1 — библиотека является первой вкладкой.** При запуске пользователь сначала
  видит сохранённые документы; диктовка и новая обработка остаются отдельными
  вкладками.
- **UI2 — пустое состояние ведёт к действию.** Если документов нет, экран
  объясняет назначение библиотеки и кнопкой переводит на обработку нового файла.
- **UI3 — документ читаем.** Выбор документа показывает источник, язык,
  длительность, номер ревизии и реплики в формате
  `[таймкод] Отображаемое имя: текст`.
- **UI4 — собеседники исправляются.** Для каждого `speaker_id` доступно поле имени;
  сохранение создаёт новую ревизию через `TranscriptStore.rename_speakers`,
  обновляет текст и не меняет исходную ревизию.
- **UI5 — варианты саммари видимы.** Все сохранённые `SummaryVariant` перечислены
  по имени шаблона; выбор показывает содержимое и версию шаблона. При отсутствии
  саммари отображается понятное пустое состояние.
- **UI6 — источник может отсутствовать.** Перемещённый медиафайл не скрывает
  документ и не блокирует просмотр расшифровки.
- **UI7 — System 7 и доступность.** Экран использует существующий QSS,
  `System7Window`, резкий чёрно-белый контраст, клавиатурный выбор списка и
  подписи у полей; важная информация не передаётся только цветом.

## Интерфейсы и файлы

- `app/ui/transcript_library.py` — `TranscriptLibraryWidget`.
- `app/main.py` — первая вкладка, переключение на вкладку новой обработки и
  обновление библиотеки после завершения задачи.
- `app/translations.py` — русские и английские ключи с существующим английским
  fallback для остальных языков интерфейса.
- `tests/test_transcript_library_ui.py` — headless поведенческие тесты.

## Допущения

- Список документов загружается синхронно: локальная SQLite-база мала, а каждый
  документ содержит только текстовые артефакты. Пагинация появится вместе с
  поиском, если реальные объёмы покажут необходимость.
- В первом UI-срезе редактируются только отображаемые имена собеседников.
- Документы обновляются при открытии вкладки и после завершения файловой задачи.
- Остальные языки интерфейса временно используют английский fallback для новых
  ключей; это не ограничивает языки распознавания.
